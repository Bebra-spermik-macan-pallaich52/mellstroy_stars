- Пять разных видов обычной атаки и пять видов супера.
- Один точный снаряд Артура; три симметричных когтя Котости; отложенная вторая игла Фога.
- Отмена очереди при смерти и запрет её переноса в новую жизнь; общий лимит 160 для летящих и ожидающих снарядов.
- Две разные цели для сферы Друна, отсутствие повторного урона внутри хитбокса, несколько попаданий в одном большом шаге.
- Три цели для супера Артура; тонкая стена по-прежнему останавливает пробивание.
- Взрыв бомбы при попадании и в конце дальности, урон по площади без двойного прямого попадания, исключение союзников, блокировка укрытием и однократное повреждение стены.
- Рикошет с расходованием остатка шага/дальности, одинаковый результат при разных разбиениях времени, ровно одно отражение игл Фога.
- Мгновенное лечение и ровно три секунды восстановления Котости; союзники/враги и дальние цели различаются.
- Сохранение 0%, 42,5% и 100% заряда после смерти/возрождения для всех пяти бойцов. Мёртвый не активирует супер; новый матч и полный сброс обнуляют заряд; смерть не возвращает уже потраченный супер.
- Разные формы визуальных эффектов, ограничение их количества, сокращённые эффекты при reduced motion, восстановление состояния Canvas даже при ошибке рисования.
- Разные частоты звуков выстрела и супера для каждого из пяти персонажей.

Две старые проверки обнуления заряда при смерти обновлены под новое требование пользователя; проверка обнуления при полном сбросе сохранена.
