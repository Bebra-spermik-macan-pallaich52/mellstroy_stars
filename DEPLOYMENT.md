# Размещение статичной игры

Проект готов к обычному статичному размещению. Сборка, Node.js, база данных и игровой сервер не нужны. Публикация сайта не выполняется автоматически.

## Проверка перед размещением

1. Выполните `node --test`, если Node.js установлен.
2. Откройте `index.html`, запустите матч, проверьте WASD, мышь, Q и паузу.
3. Проверьте звук после нажатия «Играть», завершение матча и сохранение профиля после перезагрузки.
4. Размещайте весь каталог с `index.html`, `style.css`, `js/` и `assets/`, сохраняя относительные пути.

## GitHub Pages

В репозитории откройте Settings → Pages. Выберите публикацию из ветки `main`, каталог `/ (root)`, и сохраните. GitHub предоставляет адрес после завершения публикации. Включение Pages — отдельное действие пользователя; отправка кода в GitHub сама по себе не публикует сайт.

## Другой статичный хостинг

Загрузите готовую папку без команды сборки. Начальный документ — `index.html`. Все ресурсы находятся в проекте; внешних CDN нет.

Профиль хранится в localStorage браузера для адреса сайта. Он не синхронизируется между устройствами или разными адресами. Игра рассчитана на настольную клавиатуру и мышь; узкий экран меняет компоновку, но не добавляет сенсорное управление.
