# Меллстрой Старс — этап 2

Локальная 2D-арена на чистых HTML, CSS и JavaScript с отрисовкой Canvas. Нет движков, фреймворков, игровых библиотек, сборки, внешних CDN, базы данных или обязательного сервера. Все изображения лежат в проекте.

## Как запустить

1. Скачайте проект и распакуйте архив целиком, сохранив расположение папок.
2. Откройте `index.html` в современном браузере.
3. Если браузер ограничивает локальные файлы, установите Python 3, откройте терминал в папке проекта и выполните `python3 -m http.server 8000` (в Windows можно `py -m http.server 8000`). Откройте `http://localhost:8000` на своём компьютере. Это только раздача файлов, не игровой сервер. Интернет не нужен.

Появятся арена, ваш персонаж слева, неподвижный тестовый противник в центре, здоровье обоих и индикатор заряда суперспособности. Между вами есть стена: обойдите её сверху или снизу.

## Управление и проверка

- **WASD** — ходьба со скоростью 200 мировых пикселей/с; диагональ нормализована. Последнее направление ходьбы сохраняется после остановки.
- **Мышь** — направление атаки от центра хитбокса к курсору. Пунктир показывает прицел независимо от направления ходьбы.
- **ЛКМ на арене** — выстрел. Кнопку можно удерживать; повторная атака разрешена после перезарядки.
- **Ответный огонь противника** — выключите для проверки попаданий без угрозы. Включите для проверки получения урона и смерти. Противник неподвижен, стреляет только в пределах дальности и не ищет путь. Его снаряды тоже блокируются стенами.
- **Персонаж** — смена изображения. Характеристики пока одинаковые, здоровье и заряд при смене не восстанавливаются.
- **Начать тренировку заново** — сброс позиций, здоровья, смертей, заряда и всех снарядов; выбор изображения и переключатель ответного огня сохраняются.

Попадите по противнику пять раз: он погибнет, исчезнет и вернётся через 3 секунды с полным здоровьем. Вы тоже погибаете после пяти попаданий; ходьба и новые атаки блокируются до возрождения. При смерти и возрождении состояние ввода сбрасывается: нажмите клавиши и ЛКМ заново. Заряд суперспособности сбрасывается при смерти.

Заряд растёт только от реально нанесённого урона, до 100%. Полоса сообщает о готовности, но эффект и кнопка активации пока не реализованы — это основа для будущих суперспособностей, а не обещание работающего «супера».

Выстрелы исчезают при первом столкновении с противником, стеной, границей или после прохождения максимальной дальности. Один снаряд наносит урон один раз. Выпущенный до смерти снаряд продолжает полёт, но погибший персонаж не может стрелять заново. Стена защищает даже при высокой скорости снаряда: проверяется весь отрезок движения, а не только конечная точка.

При потере фокуса или скрытии вкладки игра приостанавливается, ввод сбрасывается. Возрождение и перезарядка идут по игровому времени; возвращение во вкладку не вызывает большого скачка. Canvas сохраняет пропорции 960×640; координаты мыши учитывают масштаб и границу Canvas.

## Файлы

- `index.html`, `style.css` — страница, Canvas и интерфейс.
- `js/main.js` — единственный запуск игры.
- `js/game.js` — обновление мира, тестовый противник, обработка попаданий и смерти, перезапуск.
- `js/player.js` — общая система персонажей, здоровье, атака, возрождение и параметры.
- `js/projectile.js` — полёт и первое столкновение снаряда.
- `js/collision.js` — столкновения движения и непрерывная проверка пути снаряда.
- `js/input.js` — WASD, мышь, сброс ввода и перевод курсора в координаты мира.
- `js/map.js` — тестовая карта.
- `js/assets.js` — загрузчик изображений и кадровый аниматор.
- `js/ui.js` — здоровье, заряд, перезарядка, сообщения и счётчики тренировки.
- `assets/characters/characters.png` — подготовленные статичные изображения пяти персонажей.
- `tests/combat.test.cjs` — проверки движения и боя без сторонних зависимостей.

Логика симуляции отделена от рисования. Это поможет дальнейшему развитию, но не делает локальную игру сетевой: для мультиплеера позже понадобится отдельный сервер.

## Настройки

Все начальные характеристики заданы в `characterConfig` в `js/player.js`:

| Параметр | Начальное значение |
| --- | --- |
| Скорость | 200 пикселей/с |
| Хитбокс | 48×64 пикселя |
| Максимальное здоровье | 1000 |
| Урон выстрела | 200 |
| Дальность | 420 пикселей |
| Скорость снаряда | 620 пикселей/с |
| Перезарядка | 0,45 с |
| Радиус снаряда | 5 пикселей |
| Возрождение | 3 с |
| Урон для полного заряда суперспособности | 1000 |

Изображение сохраняет пропорции и целиком помещается внутри прямоугольного хитбокса. Рамка вокруг персонажа показывает область попадания. Точки появления: `arena.spawn` в `js/map.js` и `trainingConfig.enemySpawn` в `js/game.js`.

## Изображения и будущие анимации

Предоставленные изображения статичны. Порядок: Артур, Котость, Меллстрой Жирность, Тёмный Друн, Фог. PNG подготовлен инструментом редактирования изображений по референсам: фон удалён, в том числе зелёный фон и интерфейс телефона. Это обработанные изображения, не исходные файлы и не кадры ходьбы. Области вырезки заданы в `characterImages`.

Для анимации подготовьте прозрачный PNG с 4–8 кадрами каждого направления. Фиксируйте размеры кадров и положение точки опоры; портрет не содержит вида сзади, его нужно нарисовать отдельно. `idle` может использовать один кадр на направление.

Параметр `image` в `characterConfig` задаёт путь к PNG. `animation.animations` содержит массивы прямоугольников `{x, y, width, height}` для `idle`, `idle_up/down/left/right` и `walk_up/down/left/right`. Координаты задаются в пикселях исходного PNG, структура сетки может быть любой. `animation.fps` настраивает частоту отдельно от скорости движения. Например:

```js
animation: {
  fps: 8,
  animations: {
    idle: [{ x: 0, y: 0, width: 64, height: 64 }],
    walk_down: [
      { x: 0, y: 64, width: 64, height: 64 },
      { x: 64, y: 64, width: 64, height: 64 }
    ]
  }
}
```

Это пример формата для будущего спрайт-листа, а не описание приложенного PNG. При отсутствии состояния используется `idle`; если и его нет — статичное изображение персонажа. При ошибке загрузки выводится предупреждение и рисуется цветной маркер. На диагонали с равными составляющими выбирается вертикальное направление.

## Проверки

Для проверки логики установите Node.js и из папки проекта выполните:

```sh
node --test tests/combat.test.cjs
```

Node.js нужен только для тестов, не для запуска игры. В тестах проверяются нормализация движения, тонкие стены, дальность и порядок попаданий, одиночный урон, перезарядка, смерть, возрождение, заряд и сброс состояния.

В ходе разработки второй этап также проверен в Chromium: реальный ввод WASD и мыши, попадания, ответный огонь, смерть и возрождение обоих персонажей, индикатор заряда, очистка ввода, координаты прицела после изменения размера окна и отсутствие ошибок JavaScript.

Игровые режимы, победа и поражение матча, подвижные боты, уникальные способности и онлайн пока не реализованы. Следующий этап начинается после проверки этого прототипа пользователем.
