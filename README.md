# Меллстрой Старс — этап 1

Чистые HTML, CSS и JavaScript; библиотеки и сборка не нужны.
Откройте index.html в современном браузере. Альтернатива: из каталога проекта выполните `python3 -m http.server 8000` и откройте http://localhost:8000 на своём компьютере.

WASD перемещают выбранного персонажа со скоростью 200 мировых пикселей/с. Точка показывает направление. Переключатель позволяет проверить пять статичных изображений; это не кадры анимации ходьбы. Стены блокируют движение, вдоль них можно скользить. При потере фокуса ввод сбрасывается. Кнопка возвращает на старт. Canvas сохраняет пропорции 960×640.

Файлы: input.js — клавиши; collision.js — геометрия и движение; map.js — карта; assets.js — загрузчик и кадровый аниматор; player.js — параметры и персонаж; game.js — цикл; main.js — запуск.

## Изображения
Предоставленные изображения статичны. Они подходят как референсы или статичные спрайты после удаления фона, но не содержат кадров ходьбы. Порядок уточнён: Артур, Котость, Меллстрой Жирность, Тёмный Друн, Фог. Подготовленный с помощью инструмента редактирования изображений PNG с прозрачным фоном находится в assets/characters/characters.png. Зелёный фон и интерфейс телефона удалены. Это обработанные изображения по референсам, не исходные файлы и не спрайт-лист ходьбы. Явные области вырезки заданы в characterImages в player.js. Изображение рисуется с сохранением пропорций и привязкой к нижней границе хитбокса 32×32; визуальная картинка может выступать за хитбокс.

Подготовьте PNG с прозрачным фоном. Для ходьбы нарисуйте 4–8 кадров каждого направления; фиксируйте размер ячейки и положение точки опоры. Не растягивайте разные кадры по-разному. Idle может использовать один кадр каждого направления. Портрет не содержит вида сзади: его нужно подготовить отдельно.

В player.js параметр image задаёт путь к изображению в assets/characters/. Без кадров оно будет статичным. animation.animations содержит массивы прямоугольников `{x, y, width, height}` для idle, idle_up/down/left/right и walk_up/down/left/right. Координаты в пикселях исходного PNG; строки и столбцы могут быть любыми. animation.fps задаёт частоту. При отсутствии состояния используется idle; при отсутствии изображения рисуется маркер и выводится предупреждение. Пример конфигурации:

```js
animation: {
  fps: 8,
  animations: {
    idle: [{ x: 0, y: 0, width: 64, height: 64 }],
    walk_down: [
      { x: 0, y: 64, width: 64, height: 64 },
      { x: 64, y: 64, width: 64, height: 64 }
    ]
  }
}
```

Это описание формата, а не утверждение о структуре приложенных картинок. При одинаковых диагональных составляющих выбирается вертикальное направление. Скорость, хитбокс и частота кадров настраиваются в characterConfig. Следующий этап — бой — пока не реализован.
