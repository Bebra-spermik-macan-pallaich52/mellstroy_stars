# Меллстрой Старс — первый прототип

Локальный 2D-проект для Godot 4.3 и новее. Фактическая проверка облачной среды выполняется на Godot **4.6.3**. Язык — GDScript, рендерер — Compatibility. Внешние библиотеки, сервер и база данных не нужны.

Первый результат: один персонаж, движение WASD, направление взгляда, остановка без инерции, физические стены и тестовая карта. Дальнейшие механики добавляем после вашей проверки управления.

## Открыть и проверить

1. Установите Godot 4.x (рекомендуется 4.6.3, стандартная версия без .NET).
2. В менеджере проектов нажмите **Импортировать** и выберите `project.godot` из этой папки.
3. Дождитесь импорта изображений и нажмите **F5**. Главная сцена уже указана в проекте.
4. Двигайтесь физическими клавишами **W / A / S / D**. Они работают и при русской раскладке. Одновременные нажатия дают диагональ с той же скоростью.
5. Отпустите клавиши: персонаж сразу остановится, направление маркера сохранится, подпись сменится с `walk_*` на `idle_*`.
6. Подойдите к каждому препятствию и краям карты. Персонаж должен упираться в них и скользить вдоль стены при диагональном движении.

Скорость по умолчанию — **200 пикселей/с**. Для изменения откройте `scenes/characters/player.tscn`, выберите `Player` и измените `Move Speed` в инспекторе.

## Файлы и узлы

```text
project.godot                 настройки, главная сцена, Input Map
scenes/main/main.tscn         соединяет карту, персонажа и подсказки
scenes/characters/player.tscn отдельная сцена персонажа
scenes/maps/test_map.tscn     границы и три препятствия
scripts/player.gd            движение через CharacterBody2D
scripts/character_visual.gd   выбор состояния изображения и направления маркера
scripts/test_map.gd           рисует карту по её физическим прямоугольникам
scripts/prototype_hud.gd      подпись направления и текущего состояния
assets/characters/           прозрачные статичные изображения и маркер
tests/movement_test.gd        проверки через настоящий цикл физики Godot
tools/godot_env.sh            запуск Godot в облачном sandbox
```

Все сцены и скрипты уже созданы в полном виде. Вручную собирать узлы не нужно.

```text
Main (Node2D)
├── TestMap (Node2D)
│   └── Walls (StaticBody2D)
│       └── CollisionShape2D × 7
├── Player (CharacterBody2D)
│   ├── Sprite (AnimatedSprite2D)
│   ├── FacingMarker (Sprite2D)
│   ├── CollisionShape2D
│   └── Camera2D
└── HUD (CanvasLayer)
    └── Overlay (Control)
```

У персонажа `Motion Mode = Floating`, слой столкновения — **2 (Персонажи)**, маска — **1 (Стены)**, коллайдер — круг радиусом **18**. У стен слой **1**, маска **2**. Камера ограничена прямоугольником карты **1280 × 800**; выход игрока за карту предотвращают именно физические стены.

`Input.get_vector()` нормализует диагональ. `velocity` задаётся в пикселях в секунду и передаётся в `move_and_slide()` без умножения на `delta`. При равных составляющих диагонали выбирается вертикальное направление. После остановки запоминается последний взгляд.

## Персонажи и прозрачный фон

Порядок предоставленных референсов подтверждён пользователем:

| № | Персонаж | Референс |
|---|---|---|
| 1 | Меллстрой Жирность | Мужчина в тёмной футболке на зелёном фоне |
| 2 | Тёмный Друн | Фигура в чёрном костюме с большим капюшоном |
| 3 | Фог | Светлое лицо с тёмными глазами на чёрном фоне |
| 4 | Артур | Мужчина в костюме, с рюкзаком и пропеллером |
| 5 | Котость | Круглый трёхцветный кот |

Исходные изображения — одиночные референсы, а не готовые анимации. По согласованному мультяшному стилю подготовлен `assets/characters/characters_static.png`: **пять статичных иллюстраций на прозрачном фоне**, без зелёной и белой подложки. Это переработанные рисунки по фотографиям, а не исходные фотографии с вырезанным фоном. Чёрные участки лица и костюмов сохранены как часть персонажей.

В прототипе используется Меллстрой Жирность, остальные иллюстрации сохранены в том же атласе. Для отдельных `AtlasTexture` можно использовать следующие регионы PNG размером 1983 × 793:

| Персонаж | Region: x, y, ширина, высота |
|---|---|
| Меллстрой Жирность | 0, 0, 440, 793 |
| Тёмный Друн | 440, 0, 380, 793 |
| Фог | 820, 0, 330, 793 |
| Артур | 1150, 0, 410, 793 |
| Котость | 1560, 0, 423, 793 |

В сцене игрока область первого изображения дополнительно обрезана по прозрачным полям: `Rect2(0, 250, 440, 510)`.

Сейчас `AnimatedSprite2D` переключает восемь состояний `idle_up/down/left/right` и `walk_up/down/left/right`, но в каждом **только один статичный кадр**. Это проверка переключения состояний, не готовая анимация ходьбы. Отдельный маленький маркер показывает направление: портрет не поворачивается боком и не имитирует вид со спины. Для настоящего вида сверху нужны дополнительные рисунки направлений.

## Подготовить настоящие кадры ходьбы

После проверки первого прототипа:

1. Подготовьте согласованный вид персонажа сверху или под небольшим углом: четыре направления. Текущие портреты служат основой внешности.
2. Нарисуйте 4–6 разных кадров шага для каждого направления и 1–2 кадра стояния. Не выдавайте копии одного портрета за ходьбу.
3. Соберите кадры в PNG с прозрачностью. Например: одинаковые ячейки **128 × 128**, четыре строки направлений, по шесть кадров в строке. Не добавляйте промежутки, либо явно учтите их при нарезке. Расположение ног и центр должны совпадать между кадрами.
4. Откройте `player.tscn` → `Sprite` → `Sprite Frames`. Выберите `walk_down`, нажмите **Добавить кадры из спрайт-листа**, укажите число строк/столбцов и нужные ячейки. Повторите для остальных направлений и `idle_*`. Начальная частота ходьбы — **8 FPS**, цикл включён.
5. Настройте масштаб и положение `Sprite` под размер кадров. `Rotate Placeholder` оставьте выключенным. Сохраните названия состояний: тогда `player.gd` менять не потребуется.

## Облачная проверка

Из `/workspace/mellstroy_stars`:

```bash
# Импорт ресурсов и проверка загрузки скриптов.
bash tools/godot_env.sh --headless --editor --import

# Проверка инициализации главной сцены.
bash tools/godot_env.sh --headless --quit-after 120

# Функциональные проверки движения и столкновений.
bash tools/godot_env.sh --headless --script res://tests/movement_test.gd
```

Скрипт запуска направляет кеш и настройки Godot в доступные каталоги `/workspace`. `.godot/` — генерируемый локальный кеш, он исключён из Git. `.gd.uid` и `.import` — метаданные Godot, их можно сохранить вместе с проектом.

Headless-проверки запускают настоящий движок и физику, но не оценивают внешний вид окна и удобство управления вручную. В этой среде графический экран не подключён. После автоматической проверки откройте проект локально и выполните шаги проверки выше. Настоящие кадры ходьбы ещё предстоит подготовить; боевые механики и другие этапы пока не реализованы.

Проверено на Godot 4.6.3: импорт ресурсов, запуск главной сцены и **158 автоматических проверок в 9 сценариях** прошли без ошибок. Проверки охватывают WASD, восемь направлений движения, остановку, направления визуальных состояний, настройку скорости, все границы карты, три препятствия, скольжение и углы. Альфа-канал PNG подтверждён; внешние края атласа полностью прозрачны. Ручная проверка окна пользователем ещё не выполнена.
