# Спрайт-листы персонажей

Пять исходных стилизованных игровых спрайт-листов подготовлены по утверждённым фотографиям из `characters.png`. Исходный фото-лист сохранён. Это новая интерпретация внешности для игры: тело и вид сзади у портретных исходников дорисованы, а не извлечены из фотографии.

Каждый прозрачный PNG содержит 16 отдельных полноразмерных рисунков, 4 ряда × 4 столбца. Ряды: вниз/спереди, влево, вправо, вверх/сзади. Первый столбец используется как idle; в остальных кадрах меняются положение ног/лап и рук.

Генератор сохранил листы в размере 1254×1254. Положение персонажа внутри ячеек немного различается. Поэтому `js/spriteManifest.js` хранит точные исходные прямоугольники всех кадров. При отрисовке используется единый масштаб для всего листа (по `frameSize`) и общий нижний центральный якорь. Это устраняет сдвиги и изменение размера между кадрами без изменения пикселей изображений.

Прозрачность и четыре направления просмотрены для всех листов. Метаданные вычислены чтением альфа-канала: порог 96 отсекает слабые отдельные точки вокруг силуэта, запас 4 пикселя сохраняет сглаженные края. Прямоугольники остаются в своей ячейке.

- `arthur-walk.png`: 1254×1254, RGBA, 16 different frame pixel hashes; shared scale box 152×307.
- `kotost-walk.png`: 1254×1254, RGBA, 16 different frame pixel hashes; shared scale box 276×264.
- `mellstroy_fat-walk.png`: 1254×1254, RGBA, 16 different frame pixel hashes; shared scale box 192×282.
- `dark_drun-walk.png`: 1254×1254, RGBA, 16 different frame pixel hashes; shared scale box 207×287.
- `fog-walk.png`: 1254×1254, RGBA, 16 different frame pixel hashes; shared scale box 166×280.

Качество: это четырёхкадровый прототип ходьбы, не вручную выверенная длинная анимация. Некоторые позы повторяют близкую фазу шага; при расширении набора можно заменить лист и его метаданные. Не добавлены прыжки, бег или перекаты.

## Три бойца за монеты

`chekunets-walk.png`, `hare-walk.png`, `mytost-walk.png` созданы по трём новым референсам: человек в бутылке, белый круглый заяц с человеческим лицом, голова в голубом тазу. Фоны фотографий в игровые листы не переносились. У Мелстрой-мытости для ходьбы дорисованы небольшие руки и ступни; вид сзади у всех интерпретирован для игры. Референсные изображения не выдаются за кадры анимации.

Каждый новый PNG — RGBA 1254×1254 с прозрачным фоном и 16 разными кадрами, ряды вниз/влево/вправо/вверх. Пиксели сгенерированных PNG не редактировались. Из-за неравномерного расположения фигур точные прямоугольники определены чтением альфа-канала: 16 крупных связанных силуэтов, порог 96, отступ до 4 px. Это предотвращает обрезку ушей/рук на условных границах сетки; изолированные фоновые точки не определяют рамку. Общий масштаб и нижний центральный якорь применяются при отрисовке через `spriteManifest`.

- Чекунец: единая рамка масштаба 235×307.
- Заяц-бурмалдаец: 271×301.
- Мелстрой-мытость: 251×296.

Просмотрены целые листы, портреты и ходьба вправо/вверх в настоящем игровом цикле. Листы рассчитаны на четырёхкадровый прототип ходьбы с частотой 8 кадров/с; их можно заменить без переписывания движения. Если новый лист отсутствует, игра рисует временную цветную фигуру, а не фрагмент старого фото-атласа.
