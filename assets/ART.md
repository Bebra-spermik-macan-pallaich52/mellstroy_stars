# Оформление арен и меню

Новые иллюстрации созданы для этого проекта по стилю утверждённых игровых спрайтов. Скриншоты Brawl Stars использованы только как ориентир для композиции меню; элементы, персонажи и изображения из них не копировались.

- `maps/materials.png`: оригинальный рисованный атлас 1536×1024. Три равных столбца, два равных ряда. Верхний ряд — песок, трава, брусчатка; нижний — терракота, садовый камень, сливовый кирпич. В `js/mapArt.js` материалы берутся из своих прямоугольников с небольшим отступом от края. Рисунок не содержит препятствий или игровой разметки.
- `ui/arena-scenes.png`: три панорамные иллюстрации в равных горизонтальных полосах: двор с монетами, сад коттеджа, вечерний квартал. Используются только в карточках выбора; физическая схема арены задаётся `js/map.js`.
- `ui/lobby-pattern.svg`: небольшие собственные контурные рисунки монеты, домика, ящика и звезды для фона меню. Значки разделов — SVG в `index.html`.
- Деревянная фактура, обводки, торцы стен и тени рисуются Canvas. Их положение соответствует существующим препятствиям; декорации не влияют на столкновения.

Материалы работают без внешних загрузок и CDN. Спрайты персонажей не менялись. Палитра интерфейса собрана в CSS-переменных в начале `style.css`.
